## Parkinson's Disease Prediction Using Machine Learning

This project demonstrates the application of machine learning techniques to predict the likelihood of Parkinson's disease in individuals based on specific biomarkers. 
The dataset used comprises various features that distinguish between healthy individuals and those with Parkinson's disease, enabling the development of predictive models.


Libraries Used:
  Pandas
  NumPy
  Matplotlib
  Seaborn
  Scikit-learn
  XGBoost
  Imbalanced-learn
